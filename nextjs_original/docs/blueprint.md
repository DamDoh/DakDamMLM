# **App Name**: DakDam Binary Tree

## Core Features:

- Genealogy Tree Viewer: Display a visual representation of the member hierarchy in a binary tree structure. Each node will show member avatars, usernames, and rank badges, consistent with the original Asean SSS system. The tree should start from a selected member, with expandable/collapsible nodes for deep tree exploration, reflecting the original system's functionality.
- Navigation Controls: Implement navigation buttons to move up the upline, view left and right legs independently, and search for specific members within the genealogy tree, mirroring the navigational features of the Asean SSS system.
- Member Information Panel: Show the current viewing member's details at the top of the screen, including PV (Personal Volume) and team statistics, along with the current rank and visual badge, replicating the member information display from the Asean SSS system.
- Rank Display: Visually indicate the member's rank using the same badges as the original system (Member, Bronze, Silver, Gold, Diamond, Blue Diamond, STAR, Elite, Supervisor, Manager, Director, President, Chairman, Black Diamond, Emerald, Blue Emerald).
- Automated Member Locator: Use AI to suggest where in the MLM tree to position new members to optimize tree symmetry; present the suggested location, and ask for confirmation before committing the location. Consider PV, team size, and rank.
- Member Search: Allow users to search for members by ID or name and center the genealogy tree on that member. Show a 'PV Date' with format 01/10/2025 as a display for the PV transaction timestamp.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6), emulating the original system's aesthetic.
- Background color: Very light grey (#F0F0F0), nearly white, to provide a clean and simple base.
- Accent color: Soft green (#90EE90), analogous to the primary color, to subtly highlight interactive elements and key information.
- Font: 'PT Sans' sans-serif for both headlines and body text to maintain a modern yet readable style.
- Use simple, flat icons that are consistent with the theme, with rank icons closely matching the original Asean SSS MLM system. Visual cues should align with the MLM domain.
- Maintain a clean, organized layout similar to the original screenshot. The genealogy tree should be the focal point, with member information readily accessible. Use clear visual hierarchy to guide users.
- Incorporate subtle animations, like smooth transitions when expanding or collapsing the genealogy tree or loading member details. Avoid overly complex animations that detract from the user experience.
